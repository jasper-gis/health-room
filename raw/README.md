# 原始报告

将美年体检报告 PDF 或完整、清晰的截图放在此目录。建议文件名包含检查日期与来源，便于准确引用；不要覆盖已有报告。

放入文件后，在仓库根目录向 Codex 明确发出指令：

> 按 AGENTS.md 导入最新美年报告。

只有明确提出导入任务后才处理报告。静态页面不会自动扫描此目录，不会自动读取、解析或上传文件。

导入时需核对原文，更新 `data/labs.json`、`data/systems/*.json`、`data/profile.json`、`data/plan.json` 与 `data/ai-notes.md`。每条指标的 `source` 必须填写本目录中对应的真实文件名；单位、参考范围和日期按原报告记录。无法辨认或没有来源的数据保持未知，不补造数值。异常项标注「建议线下复诊」，AI 说明末尾保留免责声明。

`raw/` 已纳入 Git 管理，新增报告进入提交后将保留在版本历史中。这些个人健康资料和仓库历史不得发布到公开渠道。当前任务不创建远程仓库、不自动推送。

本项目仅供个人整理体检资料与学习，不提供诊断或治疗建议。任何异常以医疗机构结论为准。
