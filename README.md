# 个人健康室

蒋元甲（Jasper）的本地个人体检资料整理界面。当前为静态空壳，所有化验值均待美年报告填入，没有诊断、用药或治疗建议。

## 本地打开

在仓库根目录打开终端。当前 Windows 机器可使用已验证的 Python 3.11 启动仅监听本机的静态服务器：

```powershell
py -3.11 -m http.server 8000 --bind 127.0.0.1
```

Mac / Linux 使用 `python3 -m http.server 8000 --bind 127.0.0.1`；若 `python` 已正确指向可用的 Python 3，也可使用 `python -m http.server 8000 --bind 127.0.0.1`。

在浏览器访问 **http://127.0.0.1:8000/web/index.html**。在终端按 `Ctrl+C` 关闭服务器。

直接双击 `web/index.html` 可能因浏览器的 `file://` 安全限制而无法读取 JSON / Markdown；请优先使用上面的静态服务器。

## 当前功能

- 六个页面：身体关注、资料依据、检查与指标、用药、近期安排、AI 分析。
- 本人资料、七个身体系统、人体热点与系统选中联动、指标术语弹层。
- 2023–2026 年份时间轴；当前仅切换年份的选中状态，不筛选数据。
- 数据全部读取自 `data/`，浏览器内的操作仅改变显示状态，不写入档案。

## 目录与数据

| 路径 | 内容 |
| --- | --- |
| `web/` | HTML、CSS、JavaScript、人体 SVG 与图标，无构建工具 |
| `data/profile.json` | 本人资料与报告状态 |
| `data/labs.json` | 指标占位与未来报告来源 |
| `data/systems/` | 七个分系统的记录与关联指标 |
| `data/meds.json` | 用药资料；当前为空 |
| `data/plan.json` | 非医疗示例任务 |
| `data/ai-notes.md` | 占位说明及免责声明 |
| `raw/` | 未来手动放入的原始 PDF 或截图 |
| `_ref/frames/` | 设计参考帧，请保留 |
| `docs/superpowers/specs/2026-11-06-health-room-design.md` | 完整设计规格 |

日后将美年 PDF 或截图放入 `raw/`，再明确要求 Codex「按 AGENTS.md 导入最新美年报告」。导入方式和来源要求见 [raw/README.md](raw/README.md)。页面不会自动扫描 `raw/`，也不会自动解析、导入或上传报告；资料依据由已解析数据的 `source` 字段提供。

## 已知限制

- 纯静态、无后端、无登录、无在线同步；不提供浏览器内的档案编辑或持久保存。
- 人体为 SVG 示意，非医学影像或真实 3D 模型；器官位置仅用于界面导航。
- 目前没有原始报告。化验值均为 `null`、状态为 `pending`，其他空字段保持占位；示例安排不代表医疗计划。
- 桌面端优先对齐参考视觉；窄屏采用堆叠布局。
- 人体细节与光照采用二维 SVG，和参考视频的三维质感有差异；较矮桌面窗口需纵向滚动。
- `raw/` 和 `data/` 按规格纳入 Git，原始报告加入提交后会保留在历史中。仓库及其历史不得公开，也不要把本机服务器开放到公网。
- 本阶段只进行本地 Git 提交；不自动创建远程仓库或推送。以后若需要同步，仅使用经确认的私有仓库。
