## 本地验证

- 使用 `py -3.11 -m http.server 8000 --bind 127.0.0.1` 运行，Chromium / Playwright 打开实际页面。
- 11 个 JSON 均合法；七个系统齐全；两项化验值均为 `null`，状态 `pending`，未填来源或报告结论。
- 六个 Tab 切换与键盘左右 / Home / End 导航通过。
- 七个人体热点与系统卡片同步选中；滚动到相应卡片；次级页面隐藏引导线。
- LDL-C 术语弹层、Escape 关闭通过；计划页两项按钮跳转正确，未写入数据。
- 2023–2026 年份状态切换通过，明确提示不筛选资料。
- 1440 × 1000、1280 × 800、390 × 844 视口无页面横向溢出；窄屏指标表在自身容器内横向滚动。
- `file://` 提示本地服务器启动方式；模拟 labs.json 返回 404 时明确显示加载失败。
- 正常浏览中无 JavaScript 运行异常，无外网资源请求；`node --check web/app.js` 通过。
- 独立审查确认 JSON 文本安全转义，Markdown 不执行原始 HTML 或外链。

## 已知差异与边界

二维人体 SVG 的器官细节与光照不同于参考中的三维人体。当前资料均为占位，因此内容密度低于参考；七系统列表在桌面独立滚动，在手机完整展开。较矮桌面窗口需纵向滚动查看底部时间轴。

本轮验证使用 Windows Chromium，未实际验证 Safari。没有报告导入、预约、通知、编辑保存或真实医疗分析；时间轴不筛选数据。
